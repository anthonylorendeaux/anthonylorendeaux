## About me

Software engineer based near Toulouse, France. I work on SaaS products with Java and Angular, and I build web products with Nuxt, deployed on Vercel with tests and CI from the first commit.

Both tracks feed each other: enterprise pragmatism keeps my side projects realistic, and the product polish I ship to improves my daily engineering. Offline, I tinker with a home server and draw pixels one by one.
